# Single-Cell Cross-Species Benchmarking

## Project Overview

This independent computational biology project explores how different preprocessing strategies influence single-cell RNA sequencing (scRNA-seq) analysis and cross-species cell-type comparisons.

The project is inspired by the research objectives of ELIXIR BioHackathon Europe 2026, Project 23.

## Research Focus

Benchmarking single-cell RNA-seq preprocessing strategies for reliable cell-type identification across species.

## Objectives

- Explore publicly available single-cell RNA-seq datasets.
- Perform quality control and preprocessing.
- Compare normalisation strategies.
- Evaluate dimensionality reduction and clustering methods.
- Investigate cell-type annotation consistency.
- Explore cross-species cell population mapping.

## Technology Stack

- Python
- Scanpy
- AnnData
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
